# Схемы для понимания:

## Поток обработки объектов

Web Layer (Controller)                           - DTO для HTTP запросов
↓ (Web DTO)
Specification Layer (Service)                    - Specification для бизнес-правил
↓ (Domain Specification)
Infrastructure Layer (Repository)                - Query parameters за запроса в БД
↓ (Query Parameters)
Database

Я решил пусть каждый слой сам валидирует свой вх. сигнал:
Контроллер получил тело запроса - проверил - преобразовал его в спецификацию и отдал сервису.
Сервис получил спецификацию - проверил - преобразовал в параметры запроса к БД и отдал репозиторию.
Репозиторий получил параметры запроса к БД - проверил и выполнил запрос.
